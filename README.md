Pose-Dataset-Assembler

A tiny prototype to load small CSV or JSON pose/module datasets, normalize fields, export standardized JSON and CSV, and preview frames in-browser. No dependencies. Drop a file, or use the included example. The HTML includes conversion logic and a simple canvas preview.

Usage:
- Open index.html in a browser.
- Drop a JSON or CSV file or press "Load example".
- Inspect normalized output and download JSON/CSV exports.

This is a compact demonstration, not a production pipeline. Interpretations (field mapping) are heuristic and shown in the UI.
